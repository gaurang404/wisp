# Contributing to Wisp

Thanks for helping! Bug reports, ideas and pull requests are all welcome.

- **Bugs & ideas:** open an issue using the templates. For security issues, see [SECURITY.md](SECURITY.md).
- **Pull requests:** keep them focused — one change per PR — and include tests for behaviour changes. `swift test` must pass.
- **Setup:** see [DEVELOPMENT.md](DEVELOPMENT.md). Xcode 16+, macOS 14+, no other dependencies.

## Principles

- **Small and fast.** No dependency without a strong reason; measure anything on the launch path.
- **Secrets are sacred.** Credentials never land in plain-text files, logs or another host's requests.
- **Explain, don't just show.** Prefer telling users *why* something happened over dumping raw data.
